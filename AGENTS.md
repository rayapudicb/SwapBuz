# Swappyland Landing Web Agent Guide

This standalone public landing application presents Swappy to the world with vibrancy, elegance, and cinematic live event visuals.

## Core Rules

1. **Strictly Public & Standalone**: This web app contains zero transactional backend code, database connections, or wallet state.
2. **Design Philosophy**: High-energy, elegant, dark-mode luxury aesthetic with glowing stage lights, neon accents, and smooth glassmorphism.
3. **Visual Experience**: Immersive ambient looping video of celebrating crowds, live stadium atmosphere, and interactive event category flash showcases.
4. **Target Action**: Educate the public on bilateral swapping (sports, concerts, theatre, tournaments) and drive mobile app downloads (iOS App Store & Google Play).
5. **Performance & SEO**: 100% responsive, zero layout shift, fast initial load with lightweight streaming assets.

## Required Agent Roles

- `ui-ux-designer`: Owns the visual hierarchy, micro-interactions, dark theme palette, and responsive layouts.
- `frontend-developer`: Implements clean React, Tailwind CSS, Lucide icons, and fluid animations.
- `product-psychologist`: Crafts high-conversion copy, emotional resonance with live event fans, and clear value proposition.
- `qa`: Verifies cross-browser rendering, video playback, mobile viewport scaling, and accessibility.
